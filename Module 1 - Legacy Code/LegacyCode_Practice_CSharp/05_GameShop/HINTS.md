# Подсказки — Игровой магазин
- В `GameShop` сосредоточены покупка, продажа, скидки, бонусы, журналирование и печать.
- Найдите магические числа и строковые типы предметов.
- Расчёт скидки смешан с изменением состояния игрока.
- Возможные приёмы: Extract Method, Sprout Method/Class, DI, enum, отдельные сервисы скидок и журнала.
