# Практикум: Legacy Code и рефакторинг на C#

В архиве находятся 10 независимых консольных проектов на .NET 8.

## Состав
**Задания 1–5 с подсказками:** интернет-магазин (метод-монстр), RPG-сражение (Sprout Method), платежи (Wrap Method), RPG-инвентарь (DI и интерфейсы), игровой магазин (комплексный рефакторинг).

**Задания 6–10 без подсказок:** биллинг подписок, бронирование отеля, игровые задания, расчёт доставки, медиатека.

## Запуск
Откройте папку выбранного задания и выполните:
```bash
dotnet run
```

## Рекомендуемый формат занятия
- 10 минут — запуск и фиксация исходного поведения;
- 15–20 минут — анализ кода;
- 45–60 минут — рефакторинг;
- 10–15 минут — проверка и краткий отчёт.

## Требования к результату
1. Программа запускается до и после изменений.
2. Студент фиксирует исходное поведение.
3. До рефакторинга составляет список найденных проблем.
4. Не переписывает программу с нуля без необходимости.
5. Сохраняет бизнес-правила.
6. Объясняет, что именно изменил и почему.

Важно: в заданиях намеренно плохая архитектура, а не синтаксис. Цель — анализ чужого кода, Code Smells, рефакторинг, тестируемость и сохранение поведения.
