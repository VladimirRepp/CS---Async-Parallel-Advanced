# Подсказки — Платёжная система
- Сравните `PayWithAudit` и `PayWithNotification`: оба оборачивают `Pay`.
- Подумайте, что произойдёт при исключении внутри `Pay`.
- Обёртки не возвращают вызывающему коду результат платежа.
- Возможные приёмы: Wrap Method, общий механизм обёртки, интерфейс журнала, обработка исключений и явный результат операции.
