# Подсказки — RPG-сражение
- В `ProcessBattle` смешаны цикл боя, расчёт урона, критический удар, награда и вывод.
- Вероятность критического удара и множители зашиты в метод.
- Случайность затрудняет повторяемые тесты.
- Возможные приёмы: Sprout Method, Extract Method, настройка параметров боя, отделение расчётов от вывода.
