# Подсказки — Интернет-магазин
- Найдите метод, который одновременно проверяет входные данные, рассчитывает сумму, скидку, доставку и печатает чек.
- Проверьте магические числа: 10%, 5%, 5000, 10000, 500.
- Подумайте, как тестировать расчёт без перехвата консольного вывода.
- Возможные приёмы: Extract Method, константы, разделение проверки/расчёта/печати, SRP.
