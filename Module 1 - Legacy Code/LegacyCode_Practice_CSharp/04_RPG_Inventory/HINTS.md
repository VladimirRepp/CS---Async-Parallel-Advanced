# Подсказки — RPG-инвентарь
- Найдите создание зависимостей через `new` внутри `InventoryManager`.
- Обработчик предметов и репозиторий привязаны к конкретным классам.
- Тип предмета задан строкой; вместимость инвентаря — числом в методе.
- Возможные приёмы: Constructor Injection, интерфейсы, enum, константы, отдельные обработчики предметов.
